# Little Lot — online auction demo

Open `dist/index.html` in a modern browser. Built with HTML, CSS and vanilla JavaScript. No installation or build step.

Includes demo login (any input accepted), catalogue, search/category/sort, item details, bid validation and history, My bids, auction deadlines, order requests for winners, and demo admin add/edit/delete.

Data is saved in localStorage on the current browser. Admin is intentionally an openly labelled demonstration. Accounts, auctions and orders are not shared between devices. This is a student prototype, not secure production authentication or real payments. The demo login accepts any name and password, including blank fields as Guest. Passwords are not checked or stored. Use made-up delivery information.

Files: `dist/index.html`, `dist/style.css`, `dist/script.js`.
